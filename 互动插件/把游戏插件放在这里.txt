把游戏插件文件夹放在这里（井字棋/五子棋已内置，无需放这里）。

插件写法：每个子文件夹放一个 plugin.py，内容：
  TITLE = '游戏名'
  def create(cfg, parent=None):
      # 返回一个 QWidget 游戏窗口
      return MyGame()
深色主题可直接 from pet import theme 引用。
放好后打开右键菜单「🎮 互动」即可看到，无需重启。

安全提醒：插件是直接执行的 Python 代码，不是沙箱。只放入你信任来源的插件；不可信插件
可以读取文件、访问网络、启动程序并修改本机数据。
发布或分享时不要把插件目录中的未知 Python 文件与 exe 一起打包；插件不会经过权限隔离。
