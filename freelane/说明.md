# 白嫖通道（freelane）说明

桌宠内置的一条**免费模型通道**：聊天请求经本机代理转发到 OpenCode Zen 的免费模型，不花 API 钱。
日常使用只需要在聊天窗「⚙ 设置 → 接口 → 模型通道」里一键切换，配置文件里对应 `freelane` 段。

> ⚠️ 性质说明：上游这条车道是给其官方客户端的免费体验额度，属灰色利用，上游随时可能收紧失效；
> 聊天内容会明文发往上游，免费模型可能用于训练。不当主力生产通道用。

## 结构

- `freelane/freelane.py` —— 代理本体（纯标准库，零依赖），双形态：
  - **内嵌（默认）**：桌宠启动时后台线程常驻 `127.0.0.1:8787`（被占自动换端口），
    「模型通道」开关只决定**走不走它**；关着的时候代理只是躺着，不出网、无流量。
  - **独立**：`python freelane.py`，给调试 / 其它工具用。
- **上游请求一律直连**（显式禁用系统代理/环境变量代理）——你开不开网络代理都不影响它；
  这也修掉了"开过代理又关掉后长驻进程仍往死代理端口发请求"的 10061 问题（2026-10-09）。
- 内嵌模式的日志与会话文件在桌宠数据目录 `data/`：
  - `data/freelane.log` —— 每个请求一行：模型（含→映射/回退）、耗时、字节数、补工具数；
  - `data/freelane.state.json` —— 会话 id（额度按会话记；**删掉它 = 换新会话/新额度**）。

## 怎么用

聊天窗右上「⚙ 设置」→「接口」页最上方「模型通道」：

- **白嫖通道（本地免费）**：免 Key、免费模型；下面可填「白嫖模型」和「回退模型」。
- **自定义 API**：GLM / DeepSeek / 中转站等任何 OpenAI 兼容服务。
  切走时原配置会自动记住（含思考深度），切回来自动还原。

**保存即生效，不用重启桌宠。**模型、回退模型和别名会刷新运行中的本地代理；「测试连接」
在白嫖模式下测的是本机代理。

## 换模型 / 额度

- 查当前免费模型名单：浏览器打开 `http://127.0.0.1:8787/v1/models`
  （确切端口看 `data/freelane.log` 的启动行，通常就是 8787）。
- 名单里的模型不一定都能用（上游逐模型门禁）：实测 2026-10-08 仅 `space-bunny-free` 全通。
  **选到不能用的没关系**——代理自动回退到「回退模型」，日志里带 `[回退]` 标记。
- 上游漂移时（比如 space-bunny 哪天没了）只需改配置，**不用重新打包**：
  设置界面里改「白嫖模型 / 回退模型」，或直接改 config.json 的
  `freelane.model` / `freelane.fallback_model`；别名映射在 `freelane.aliases`。
- 额度打满（429）：等几分钟；长时间不恢复就删 `data/freelane.state.json` 重启桌宠换会话。

## 独立模式（给其它工具 / 调试）

```bat
python freelane.py --port 8790          :: 手动指定端口
python freelane.py --new-session        :: 换新会话
```

其它工具把 OpenAI 兼容端点指到 `http://127.0.0.1:8787/v1`、API Key 随便填即可。
桌宠正在运行时内嵌代理已占 8787，独立实例会提示"已有服务在监听"并退出（正常现象）。

## 排错

- 聊天报连接错误：先看 `data/freelane.log` 最后几行；常见是上游 429 / 地区门。
- 常见上游报错含义：

  | 报错 | 含义 | 处理 |
  | --- | --- | --- |
  | 403 free tier can only be used from within OpenCode | 该模型门更严 | 换模型（代理一般已自动回退） |
  | 401 Model ... is not supported | 在目录但已不可路由 | 换模型 |
  | 429 | 免费额度打满 | 等待 / 换会话 |
  | 地区门 | 出口 IP 不被上游接受 | 换网络出口 |

- 想看实时日志：命令行里 `cd freelane` 后 `python freelane.py`（独立模式，有窗口实时输出）。
